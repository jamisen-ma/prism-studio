## Honest help and identity copy

Always-visible copy: **“Apply a colored filter to RGB. Transparency stays unchanged.”** Put detailed explanations in an accessible collapsed **How Photo Filter works** disclosure:

- Density controls colored transmission, not interpolation toward a solid fill. With preservation off it can darken the image; black remains black.
- Preserve Luminosity restores the input's weighted encoded-RGB brightness before final byte rounding. It is not calibrated white balance, perceptual lightness, linear-light optics or Photoshop pixel equivalence. Gamut fitting can reduce chroma near the RGB boundary.
- With preservation on, pure white and saturated primaries remain unchanged; neutral midtones may gain color. Density 100 does not mean replacement with the chosen color. At zero transmission the defined preserved result is the original RGB, including a black filter at full density.
- Density zero or a white filter produces the original-color candidate; any gray filter does so with preservation on. For source filters, non-Normal filter blending can still change RGB, and structural source-edit/Bake restrictions still apply. Never call an identity candidate a disabled entry.
- Source entries run in source order before transforms; the effect mask mixes the completed stack and the layer mask controls visibility. Global scope uses the existing adjustment mask/opacity. Alpha and fully transparent RGB are retained by the native color mapping.

Show a short conditional identity note for these metadata identities, qualified by source blend mode. Do not reproduce numerical formulas or work accounting in the main workflow. Native limit refusals retain the exact draft; no automatic reduction, bake or replay.
